Engineering Architecture

How Virgo Protects Your Data

Most AI agent frameworks demand cloud APIs and leak intent via clearnet searches. Virgo is engineered from the ground up for strict local-first execution.

01

Strictly Opt-In Egress

Out of the box, zero user queries hit the public internet. Web search and URL scraping tools run through prioritized failover tiers, natively supporting bundled Gluetun VPN tunnels and authenticated proxies.

02

Durable Agent Sagas

Long-running autonomous tasks survive pod evictions and node reboots. By decoupling workflow state from the API process using Temporal, Virgo ensures execution guarantees for complex multi-agent reasoning loops.

03

Deep Semantic RAG

Massive documents are automatically chunked and ingested via local fastembed BM25 sparse vectors and LiteLLM dense embeddings. Context retrieval is merged via Reciprocal Rank Fusion (RRF) and reordered by a HuggingFace TEI cross-encoder.
