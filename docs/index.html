Engineering Architecture

Real-Time Interjection

Unlike traditional agents where you fire a prompt and wait, Virgo's asynchronous architecture allows for true real-time interjection. You can interrupt, steer, or correct an agent mid-thought or mid-execution natively.

[ Interactive interjection GIF will go here ]

Adaptive User Memory

Virgo doesn't just execute commands; it learns how you operate. Built-in conversational memory allows the system to continuously adapt to your infrastructure and coding style. This intelligence is strictly partitioned per account by default—your personal agent grows alongside you while remaining entirely private.

[ Memory partition architecture diagram ]

Strictly Opt-In Egress

Out of the box, zero user queries hit the public internet. Web search and URL scraping tools run through prioritized failover tiers, natively supporting bundled Gluetun VPN tunnels and authenticated proxies.

[ Network topology / VPN routing visual ]

Durable Agent Sagas

Long-running autonomous tasks survive pod evictions and node reboots. By decoupling workflow state from the API process using Temporal, Virgo ensures execution guarantees for complex multi-agent reasoning loops.

[ Temporal durable execution flow ]

Deep Semantic RAG

Massive documents are automatically chunked and ingested via local fastembed BM25 sparse vectors and LiteLLM dense embeddings. Context retrieval is merged via Reciprocal Rank Fusion (RRF) and reordered by a HuggingFace TEI cross-encoder.
